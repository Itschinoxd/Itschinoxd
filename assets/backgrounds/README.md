# Fondos del proyecto

Coloca tus imágenes aquí con estos nombres exactos:

- `panel-principal.jpg` → fondo del panel principal (inicio).
- `catalogo.jpg` → fondo de la sección catálogo y del lector PDF.

Puedes usar `.png` si prefieres, solo recuerda actualizar en `styles.css` y `reader.css` las variables:

- `--bg-main`
- `--bg-catalog`
